# Jarvis API

Backend service for the Jarvis automated trading platform.

## Features

- Receive MT5 EA status
- Enable/Disable trading
- Store EA status
- AWS Lambda
- API Gateway
- DynamoDB

## Stack

- Node.js
- AWS Lambda
- API Gateway
- DynamoDB
